# Cross-platform fixtures

This directory is where a **real** `.securevault` file generated by the tested Android build
belongs. It is currently empty, and that is the honest state of cross-platform interoperability.

`WireFormatTest` proves the format constants have not drifted. `BackupFormatTest` and
`RestoreBoundaryTest` prove the portable reader handles well-formed and hostile files correctly.
None of that is the same as proving an Android-written file opens here — those tests write the
file with the same code that reads it, which cannot detect a shared mistake.

To close the gap:

1. On the tested Android build, create a vault containing at least one of every item type, with
   folders, tags, favourites, custom fields, a TOTP secret and at least one attachment.
2. Create a backup and note the master password used.
3. Copy the `.securevault` file here as `android-v2-reference.securevault`.
4. Record the password and expected contents in `android-v2-reference.json` beside it.
5. Add a test that opens it through `BackupCodec` and asserts every field survives.

Until step 5 passes, interoperability is **designed and format-tested, not verified**, and should
be described that way in README.md and SECURITY.md.
